# Fedory GRUB theme.
#
# Colours are the Fedory Vesper palette (themes/fedory-vesper/colors.toml), so
# the boot menu, the Plymouth splash, and the SDDM greeter read as one system.
#
# Deliberately free of widget pixmap slices: menu elements are drawn with plain
# colours rather than brittle *_c.png/_w.png sets. The background is the Vesper
# Glasshouse artwork, installed as background.png by bin/fedory-refresh-grub.
#
# fedory.pf2 is generated at install time by bin/fedory-refresh-grub and lives
# in this directory on the installed system. /etc/grub.d/00_header scans the
# theme directory and emits a `loadfont` for every .pf2 it finds, which is why
# the font has to sit here rather than in /boot/grub2/fonts.
